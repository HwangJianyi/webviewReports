# react-native-webview_v1 接口规格说明

## 1. 概述

- 上游原库地址：D:\rnDev\enhance\react-native-webview（本地路径）
- 鸿蒙化仓库地址：D:\rnDev\enhance\rntpc_react-native-webview（本地路径）
- 库功能描述：React Native WebView 是社区维护的 WebView 组件，用于在 React Native 应用中嵌入网页视图。支持 iOS、Android、Windows、macOS 平台，同时支持旧架构（paper）和新架构（fabric）。可作为 React Native 内置 WebView 的替代方案。

## 3. JS/TS 层导出接口

### 3.1 类 (Classes)

#### WebView

`WebView` 是核心组件类，继承自 `React.Component<WebViewProps>`。在 iOS 和 Android 上通过 `forwardRef` 实现，鸿蒙化版本同样使用 `forwardRef`。

| 序号 | 类名/成员 | 方法/属性 | 功能描述 |
|------|-----------|-----------|----------|
| 1 | WebView | goBack() | 在 WebView 历史记录中后退一页 |
| 2 | WebView | goForward() | 在 WebView 历史记录中前进一页 |
| 3 | WebView | reload() | 重新加载当前页面 |
| 4 | WebView | stopLoading() | 停止加载当前页面 |
| 5 | WebView | injectJavaScript(script: string) | 向 WebView 注入 JavaScript 代码 |
| 6 | WebView | requestFocus() | 请求 WebView 获取焦点 |
| 7 | WebView | postMessage(data: string) | 向 WebView 发送消息 |
| 8 | WebView | clearFormData?() | (Android only) 移除当前焦点表单字段上的自动填充弹窗 |
| 9 | WebView | clearCache?(includeDiskFiles: boolean) | 清除资源缓存（应用级别） |
| 10 | WebView | clearHistory?() | (Android only) 清除内部前进/后退列表 |
| 11 | WebView | static isFileUploadSupported: () => Promise\<boolean\> | 检查是否支持文件上传（iOS 始终返回 true，Android 需检查版本） |

导出方式：`直接导出`（入口文件 `export default WebView`）
